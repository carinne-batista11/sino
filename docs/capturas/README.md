# Capturas de tela da v6.0

(janela "Sino — Demonstração", banco próprio, serviço de códigos e caixa de
mensagens no próprio computador). A conta ("Lúcia Exemplo", `demo@sino.local`)
e todas as contas exibidas são **fictícias** e foram cadastradas pela própria
interface. Nenhuma imagem mostra senha ou código. Janela maximizada, 1294×741.
